## 重要限制与取舍

1. Android + 普通 USB-RS485 转换器**不能保证**精确复原 Modbus RTU 的物理 `t1.5/t3.5` 静默时间；软件只能提供有界、保守的候选帧解析与实测互操作保证。
2. **本地虚拟从站接入单主站直连**作为基础场景；**已有多从站总线混流**作为高级兼容场景进行专项测试，不声称全设备通用兼容。
3. 扫描到 CRC 正确不代表候选帧方向和边界可信，更不代表允许写入。
4. 不增加 Modbus TCP、S7、DL/T645、Lua、商业软件工程兼容、云端或跨平台功能。
5. 本包没有生成任何可运行 Kotlin 工程，只有文本工程规格与参考路线。
