# 注意事项（贡献与评审必读）

本文记录老板和技术总工对本项目的持续要求。**每一轮有新要求都要补进来**；不要放截图，不要放任何隐私信息。

## 一、安全与交互
1. **写入前一律确认**：任何写寄存器/线圈的入口都先弹确认层，显示“读取值 / 上次写入 → 新值”、将发送的整帧字节、超时不重试提示；**取消不发送**，点“发送”才发且只发一次。
2. **广播（Unit 0）**：确认层用红色（红色标签“广播 · 所有从站”、红色“发送广播”按钮），提示“所有从站都会执行，且不会有回应”；结果只能标“已发送”，不能写“成功”。
3. “当前”值的来源要标清：来自上次写入标「上次写入」，来自读取标「读取值」，没读过标「当前 / 未读取」；新旧值相同给一句提示（不拦截）。
4. 编辑面板（面板的编辑模式）期间**不得发送任何写入**。

## 二、视觉与布局
5. **设计稿以 v2 为准**（`docs/design/ui-v2.html` 及 `v2-b*.png`）。对不齐的必须逐项量出来对齐：间距、圆角、阴影、字号、基线、左右留白；不接受“差不多”。
6. **分段滑块同心**：选中块圆角 = 外层容器圆角 − 内边距（现为 12 − 3 = 9），四周内边距都是 3dp，左右对称；全局只有 `SegmentedControl` 一个实现，不要另写。
7. **阴影形状必须与被投影元素的圆角一致**（dock、岛、卡片）。
8. **触控区域 ≥ 48dp 优先，视觉仍用设计稿尺寸**：视觉块可以更小，但可点击的热区要补到 48dp。
9. **dock 的样式和位置是老板授意的**：底部间距贴近系统手势条上沿（约 8–12dp），内容区底部留白随之调整；**不得改回参考图的位置**。
10. 连接页：页头标题「连接」下面**不要**「主站 · 运行中」之类的副标题；卡片内标题行与内容的间距按稿面收紧，并有间距断言。
11. 连接后的「断开」条**不得遮挡**任何内容：条放在可滚动内容之外，内容区留出底部空间，滚到底最后一张卡完整可见（竖屏、横屏都要有测试）。
12. 每个视觉修复都要有断言（`getBoundsInRoot` / 像素）+ Roborazzi，含字体缩放 1.3 和窄屏；断言必须能在“去掉修复”时失败。

## 三、日志页
13. 分页（默认每页 100 帧）；工具栏有 **开始 / 暂停 / 清除 / 保存**。
14. **默认不记录，点“开始”才记录**；暂停停止记录但保留已有帧；清除清空；“暂停记录”≠“锁定滚动”，文案和图标要区分。
15. 每帧记录墙钟时间 `HH:mm:ss.SSS`，**保存的文件也带时间**（CSV 另带完整日期）。
16. 记满 20000 帧（或约 8MB）停止并提示，不静默丢旧帧。
17. 保存走系统界面（保存到文件 / 分享），**每次保存前弹隐私提示**；不申请存储权限，不上传。

## 四、面板
18. **不放空壳、不放示例卡**：没有配置点位时显示空面板和“添加组件”入口。要做就做完整功能（编辑、选类型、数值/曲线配置、系列编辑），按 `docs/panel-plan.md` 分多个 PR 逐步做，每个 PR 独立可合并。
19. 面板的实现放 app 层 `application/panel/`（纯 Kotlin、无 Android 依赖，可整体搬进 core）；序列化用 `org.json`；轮询与手动请求交错；不做后台采集；样本历史只放内存。

## 五、边界与流程
20. **协议和 `modbus-core` 不动**（2026-10-17 老板放开：后端可以直接改，含 modbus-core；改协议行为必须有测试，已有用例不能改弱）。依赖 core 的项目单列“暂缓清单”（`docs/deferred-core.md`），例如：会话条 TX/RX/错误计数（`SessionCounters`）、写入帧预览 `SessionManager.previewFrame()`、帧摘要 `FrameDescriber`、`TrafficEvent` 的 id/配对、`RegisterChange.source`、`ValueSimulator`。不要为了赶进度把这些做成假数据或空壳。
21. **实机截图含隐私，不进公开仓库**，也不贴进 PR 描述；PR 里只用 Roborazzi 渲染图和设计稿渲染图。
22. 本地构建优先使用可用的 Android SDK/JDK 直接运行 Gradle（2026-10-18 老板明确：本机具备 APK 构建环境和 Android 模拟器，可本地测试截图；不再以 `/opt/android/build.sh` 缺失阻止验证）。**一次只跑一个本地构建**，用完 `./gradlew --stop`。不提交录制出来的基线 PNG；模拟器截图只留本地。模拟器必须有可见窗口，不使用 `-no-window`（老板明确要求）。老板已授权清理模拟器测试存储、每次构建卸载旧测试包后重装。
23. 不编造验证结果：没验证的写“未验证”（尤其是真机触控、字体渲染、手势条位置）。
24. 堆叠的 PR 之间用普通 `git merge` 同步，不 force push。**合并进 main 必须由老板本人在聊天里明确确认**，合并提交带 `[skip ci]`；在确认之前所有 PR 保持不合并。
25. 每个里程碑（推送 / 本地构建 / CI 结果）都记到 `board.md`。
26. **「我的」页**：入口只放有真实功能的分组（外观 / 显示与格式 / 安全 / 通信默认值 / 关于）；没有数据来源的卡片（工程、导入导出、历史会话、本地存储）不画占位。二级页用 ← 返回，横屏是左分组 + 右详情。
27. **设置项必须真的生效或明确标注**：每个开关都要有存储和使用方（例如「线圈写入额外提示」控制写入确认里的那一句，「通信默认值」是连接页高级设置的初始值，用户在连接页手动改过的值不会被覆盖）。「写入前确认」不可关闭，界面上只显示「始终 🔒」。
28. **输入框不放进对话框**：数值输入在页内编辑（输入不合法就不能保存，错误文案与连接页一致），避免对话框窗口里的键盘 / 焦点问题。
29. **面板不放示例数据**：没有点位就显示空状态，不放假卡片、假曲线、假的「添加」按钮；没有来源的数字不上屏。
30. **工程文件不丢数据**：写入用临时文件 + 备份 + 原子重命名；读不懂的内容原样保留；更新版本写的文件只读；程序不自动删除工程数据。写入设备的数值超出类型范围一律拒绝，不静默回绕。
31. **面板读取不能骗人**：没读到的值显示「—」不是 0；读取失败显示上一次的值时必须同时说明「读取失败，显示的是上一次的值」；换连接后旧值清空；面板只在主站会话在跑且页面在前台时才发请求。
32. **新增 SDK 调用要对照 minSdk 26**：`BigInteger.TWO` 这类 API 33 才有的成员 lint 会拦（P1 踩过），用 `BigInteger.valueOf(2)`。
33. **面板卡片尺寸对稿（v3，2026-10-24 改）**：卡片圆角 16 / 内边距 10×12（内容离外缘 13×11）/ 网格间距 8 / 同行等高；名称 13（名称行最小高 22，有无标签都对齐）；值字体 mono 28 SemiBold；底行 meta mono 10.5，推到卡片底部（左地址、右阈值 / 量程 / Unit）。灯 18、进度条高 10。改面板排版必须同步改 `PanelWidgetsTest` 里的数值断言。
34. **没有功能的入口不画**：面板页现在有 ✎（编辑，P5 起）和「＋ 添加组件」（P6 起，真能产生组件），⤢（P8a 起，曲线卡右上角和页头 ✎ 左边（v3），只在当前面板有曲线时出现）；不放灰掉的按钮。向导里的组件类型只列已经能用的 6 种（数值 / 曲线 / 指示灯 / 状态文本 / 进度条 / 仪表），其余（开关 / 寄存器表 / 按钮）只在一句提示里说明“后续版本加入”，不画灰卡片。
35. **编辑面板是草稿制**：进入编辑后所有修改（改名、列数、排序、尺寸、删除、新建 / 删除面板）只改内存里的草稿，点「完成」才写盘；✕ / 返回键在有修改时先问「放弃修改？」。编辑模式只读不写，不会向设备发任何写入请求（`PanelEditFlowTest` 断言）。读不懂的组件在编辑、排序、保存中原样保留。
36. **编辑手势必须有不用手势的替代（v3 改）**：长按拖动排序仍保留；其余操作都在“点选 → 底部工具条”里：尺寸分段（1×1 / 2×1 / 2×2 / 1×2，曲线只有 2 列的）、前移 / 后移（两端置灰）、配置、删除（红色，最右）；工具条按钮高 52、热区 ≥48。卡片上不再画 × 和角标（原来 20dp / 12dp 视觉 + 48 热区）。无障碍动作有「前移 / 后移 / 配置 / 删除」。编辑卡最小高 84；改编辑卡片尺寸时同步改 `PanelEditTest` 里的断言。
37. **字体放大 1.3 倍要看一眼**：面板卡片和编辑卡片在 1.3 倍字体下值 / meta 不能溢出卡片（`PanelEditTest.fontScale13*` 断言），渲染图 `docs/review/ui-pr-p5/*font13*`。
38. **添加组件向导对稿（v3）**：第 1 步按「显示读数 / 控制设备 ⚡」分组，紧凑横排卡（高 ≥62、44dp 示意图、圆角 14），一屏放下，不画灰卡片；第 2 步顶部是一行实时预览（琥珀边 + 名称行右侧「预览」徽标），下面是数据点位、换算与轮询（折叠成一行摘要，点开再改；16 位类型不画字序控件，只留一句说明）；名称 / 单位 / 小数位 / 阈值 / 尺寸都在第 3 步。底栏「上一步」:「下一步」= 1 : 1.6、高 52；所有可点元素触控 ≥ 48dp（`PanelWizardTest` 逐项断言）。
39. **向导不会向设备写任何东西**：预览只发读请求，且用独立的轮询器（`PointPreview`），不污染面板真实数据；未连接 / 从站角色时预览显示原因、不发请求（`PanelWizardFlowTest` 断言整个向导过程无写请求）。会写设备的组件（开关 / 按钮）属于后面的 PR，必须带“写入前确认”。
40. **向导里的校验**：必填项在点“下一步”前不报红，但输入了不合法的内容立刻提示；点“下一步”有错时留在当前页并提示。数据类型只给当前区域允许的几种（线圈 / 离散只有 BOOL）；占用寄存器数实时显示，超出范围有明确提示。
41. **向导的草稿同样不写盘**：向导完成只是把组件放进编辑草稿，点编辑页“完成”才写工程文件并开始轮询；v3 起编辑模式隐藏 dock / 侧栏（全屏专注），编辑中不能切到别的页面；退出编辑后 dock 恢复（`editModeHidesTheDockAndKeepsTheDraftUntilDone`）。
42. **曲线样本只放内存**：`SampleHistory` 按点位 id 存环形缓冲（保留时长 + 点数上限双限制），不落盘、不后台采集（只有主站会话在跑且面板页在前台时才轮询，轮询才记样本）；退出 App 即清空。只记曲线用到的点位；点位定义改了就清掉它的旧样本；时钟被调回的样本丢弃。工程文件里只有曲线配置没有样本（`PanelCurveFlowTest` 断言）。
43. **曲线读不到不能画成 0**：读取失败记“失败标记”（连续失败只记第一次），到下一个有效样本之间是缺测段——画斜纹 + 断开（或仅断开，按配置）；超过“3 个轮询周期（至少 3 秒）”没新样本的空档也算缺测；游标落在缺测段里显示“—”，不插值。
44. **曲线性能约束**：界面最多 4 fps 重绘（250 ms 一拍，稿面要求 ≤10 fps），只在页面处于前台时拍；每条线先抽成最多 600 桶（保留每桶首 / 最小 / 最大 / 尾）再画，所以点数上限 100000 也不会拖慢界面。**高采样率 × 8 系列的真机流畅度未验证**。
45. **曲线卡里不能用 `BoxWithConstraints` / 其它 SubcomposeLayout**：面板网格按行取固有高度（`maxIntrinsicHeight`），SubcomposeLayout 不支持，会直接崩（P7 渲染时踩过）。需要尺寸用 `onSizeChanged`。
46. **曲线向导对稿（v3）**：第 2 步 = 顶部实时预览（标题「实时预览 · 窗口」+ 右侧「预览」徽标）+ 系列列表（块内标题「系列 N / 8」，最多 8 个；行内只有颜色点、名称、来源、轴标签，不画线宽 / 线型样例）+ 时间窗口 + 「采样与内存」折叠块；第 3 步「显示」才有坐标轴（右轴块只在有系列用右轴时出现）、网格、图例、缺测与游标。系列在页内浮层（遮罩 + 贴底面板，不是系统对话框，因为里面有输入框）里编辑，“完成”钉在浮层底部；数据点位是单独一页（复用数值组件的数据源 / 换算表单），页面上有自己的“完成”。曲线只能 2 列宽（尺寸 2×1 / 2×2），第 3 步预览放在虚线“假网格”里。所有可点元素触控 ≥ 48dp（窗口时间芯片、色板用 `minWidth` / 48dp 方块保证）。
47. **曲线编辑页不画实时图**：编辑模式里曲线卡只显示名称、“N 个系列 · 窗口”和图例（编辑期间不重绘、不读数），保存后才回到实时图。曲线最小 2 列：编辑模式的改尺寸循环、拖角标都不会把曲线缩成 1 列（`ProjectEdits` 的 `minColumns`）。
48. **曲线向导同样只读**：预览用独立的 `PointPreview` 多点位预览（自己的样本历史，只留 10 分钟 / 5000 点，关向导即丢），不碰面板的真实历史；整个向导过程不向设备发任何写请求（`PanelCurveFlowTest` 断言）。写设备的组件（开关 / 按钮 / 寄存器写入）在 P8，必须走写入前确认。
49. **曲线全屏**：路由 `curve?id=<曲线组件 id>`；入口只有曲线卡的 ⤢ 和面板页头 ⤢（都 ≥ 48dp），找不到该曲线就只写原因、不画空图。横屏自动进入（设置“横屏自动切换曲线全屏”）只在“面板页 + 当前面板有曲线”时发生；手动关闭后回竖屏前不再自动进。全屏页前台时继续轮询（`PanelRuntime.setActive(owner, …)` 按所有者计数，页面切换不会误停轮询）。
50. **曲线快照**：PNG 里有点位名称和数值，**每次保存前先弹隐私提示**，取消什么都不写；保存走系统保存界面或 `FileProvider` 分享（`cache/exports/`，只留最近一张），不申请存储权限、不联网；快照按钮本身不画进图里（`PanelFullscreenFlowTest` 断言取消不落文件、确认后是合法 PNG）。真机的保存 / 分享界面未验证。
51. **仪表组件**：量程必须 min < max（默认 0–100），值在量程外时弧停在端点但读数照实显示；没数据只画底轨和“—”；预警 / 告警区间画在底轨外侧的细带上。仪表是只读组件，**没有任何写入入口**。写设备的组件（开关 / 按钮 / 寄存器表）仍在 P8b，必须走写入前确认（取消不发、广播 Unit 0 红色确认、位写入先读后写提示），复用现有 `WritePlanner` / `ConfirmSheet`。
52. **面板写设备只有一个入口**：开关 / 按钮 → `PanelWriteController` → 工作台同一个 `WriteConfirmSheet`（整帧预览）→ 点“发送写入”才发；取消 / 点弹窗外什么都不发。任何新的会写设备的面板组件（P8b2 的寄存器表等）都必须走这条路，不允许在卡片里直接 `session.execute` 写。
53. **编辑模式、向导预览不能写设备；从站 / 未连接不能写**：编辑或向导打开时控制器拒绝一切请求（连读也不发）；进编辑模式时未确认的弹窗作废；卡片在这两种场景里是“只画样子”（开关没有切换动作、按钮不是真按钮，不能用 disabled 的 `clickable` 代替——它会吞掉“点卡片打开向导”）；从站 / 未连接时开关 / 按钮置灰并写原因。
54. **广播（Unit 0）只给按钮**：确认弹窗红色徽标 + 红色“发送广播”，卡片上红字写明“广播（所有从站）”；结果只写“已发送，无法确认从站是否执行”，不写“已写入”。读取类组件、开关（要读状态）仍然只能 Unit 1..247。
55. **寄存器位写入 = 先读整字 → 改一位 → 写回**：弹确认前先 FC03 读整字，确认弹窗里写明非原子并按 16 进制显示整字变化；点“发送写入”后再读一次核对，整字变了就不发、用新整字重新确认；任何一次读失败都不写。开关状态未知 / 过期 / 超时时开关置灰，不对看不到的状态做“取反”。
56. **开关 / 按钮的工程格式是纯增量**：`kind = switch / button` + `buttonLabel` / `writeValue`，`FORMAT_VERSION` 仍是 1；旧版本把它们当“不认识的类型”原样保留。文件里不满足规则的开关 / 按钮（开关广播 / 离散输入 / 整个寄存器、按钮没预设值 / 预设值越界）整个组件按“读不懂”保留，不渲染。按钮不进轮询，所以只有按钮的工程不显示“轮询中”。
57. **寄存器表的行就是点位**：第 i 行是一个独立的派生点位（地址 = 起始地址 + i × 每行寄存器数，同 Unit / 区域 / 类型 / 字序 / 缩放 / 轮询周期），读取、合并、过期 / 错误都沿用点位的规则。最多 16 行；类型限 U16 S16 U32 S32 F32（寄存器区）或 BOOL（线圈 / 离散）。徽标和页脚按最差一行显示。
58. **寄存器表默认只读，“允许面板修改”默认关**：只有保持寄存器 / 线圈的表可以打开，输入寄存器 / 离散输入锁定为关。打开后每行有 ✎（触控 ≥48dp），写入一律走和开关 / 按钮同一条路：行内输入新值 → “下一步”→ 生成写入计划 → 和工作台同一个确认弹窗（整帧 hex、当前 → 新值）→ 点“发送写入”才发；取消 / 点遮罩 / 返回键什么都不发。线圈行不用输入，直接确认（目标是当前状态的相反值，未知则 ON，确认里可改）。
59. **寄存器表的写入守卫**：编辑模式里 ✎ 不出现、向导预览里 ✎ 只画样子不可点；从站 / 未连接时 ✎ 置灰并写原因；同一时间只有一个写入流程（输入框开着时新的请求被忽略）；离开面板页、进编辑 / 向导时输入框作废。输入的值按点位的缩放 / 偏移反换算、四舍五入并做类型范围检查，不合规在输入框里提示，不会发出越界值。
60. **寄存器表的输入浮层是页内浮层，要坐在 dock 上方**：不用系统对话框（带输入框的 Dialog 在测试环境里会挂起），浮层底部留出 dock 的高度，否则“取消 / 下一步”会被悬浮 dock 盖住。
61. **寄存器表的工程格式是纯增量**：`kind = register_table` + `tableRows` + `tableWritable`，`FORMAT_VERSION` 仍是 1；旧版本当“不认识的类型”原样保留。不合规的表（行数不在 1..16、类型不允许、可写但区域是输入 / 离散、跨度溢出）整体保留不渲染。

## 六、导入与本轮细化（2026-10-24）
62. **导入只认配置，只替换不合并**：只读导出 ZIP 根目录的 `default.json` / `slave.json`，其余文件列为“不导入”；ZIP 读取 256 MB、单个配置 4 MB 上限；更新版本的文件拒绝导入；原文写入并先另存 `*.before-import-<时间>`。有会话时拒绝导入；导入后不连接、不写设备、不启动从站；已打开的面板自动重读并丢弃进行中的编辑（`ArchiveImportTest` / `PanelImportReloadTest`）。
63. **表单校验没通过要看得到**：点“下一步 / 完成”有错时，把第一个出错的输入框滚进可见区域（`ErrorReveal`，`PanelWizardFlowTest.nextWithAMissingNameScrollsTheNameFieldIntoView`）。长表单里错误在首屏外，按钮看起来像没反应。
64. **“多久之前”用合适的单位**：1 分钟内用秒，1 小时内用分钟，1 天内用小时，再久用天（`ElapsedAge`）；不出现几十万秒这种读不出新旧的数字。
65. **预览卡要一眼看出是预览**：向导预览卡名称行右侧带“预览”徽标（稿面为“实时预览”）；没名称时写“未命名组件”，不写像输入框标签的“名称”。
66. **交给系统界面就收起浮层**：导出的“保存到文件 / 分享”一开始就关掉导出浮层，回来不用手动关。
67. **云端工具的边界**：云编译只出 APK（ARM64 上 Robolectric/Conscrypt 没有原生库，`test`/`full` 模式必然失败，单测看本地和 GitHub CI）；redroid 渲染有延迟，自动化点击之间要停顿，否则会点到下一屏；云构建签名与旧安装不同时要先卸载（测试设备，老板已授权清理测试数据）。设备不可用时写“未验证”，不拿 Roborazzi 渲染代替设备验收。
68. **名称、图标与署名（2026-10-24 老板要求）**：应用名 **Corn Modbus**（玉米图标，自适应图标前景是原图 76dp 居中、背景 #232323、带单色主题层）；包名 `io.github.xingyingyuzhui.modbusmobile` 不改（保证老安装能升级）。「我的」页设置列表最后、完整设置页最后都有“Corn Modbus · by xingyingyuzhui”，「关于」里有“作者 · xingyingyuzhui”，都打开 https://github.com/xingyingyuzhui/corn-modbus（交给系统浏览器，应用仍不申请 INTERNET）。作者信息还在 `Authorship`、BuildConfig（`APP_AUTHOR` / `APP_REPO`）、manifest meta-data 和每个导出 ZIP 的注释里，改动时保持一致，不要删。

## 七、面板 v3（2026-10-24 老板定稿 `docs/design/panel-v3.html`，「按照这个设计，开始改动」）
72. **页头两行**：标题行（⤢ ✎）+ 一行「面板页签 · 轮询胶囊」，不再有会话条和面板 chips；只有一个面板时页签也显示它的名字。横屏把标题、页签、胶囊、⤢ ✎ 收进一行。胶囊：轮询中写实际周期并带暂停键、已暂停（琥珀，▶ 继续）、未连接（灰，点了去连接页）、从站模式、只有按钮时写「主站」；热区 ≥48（`PanelWidgetsTest` 胶囊用例）。
73. **正常不打标签、不写时间**：只有预警 / 告警 / 过期 / 超时 / 错误才在名称行右侧打标签；预警琥珀描边、告警红描边 + 红底。过期必须写「读取失败 · N 秒前的值」（规范 31 的说明 + 多久以前，单位按规范 64），有过期卡时每秒更新。
74. **控制卡和读数分开**：会写设备的卡（开关、按钮、可修改的寄存器表）名称前有 ⚡，只读寄存器表是 🔒；按钮是浅底描边的 `TonalButton`（视觉 44，热区 48），广播按钮红色，并在名称下方单独一行红字「广播（所有从站）」。写入流程不变（同一个确认弹窗）。
75. **寄存器表三列**：地址 | 值（HEX 小字在值下面）| 灰色 ✎ 提示；行高 ≥48，可修改时整行可点（只是请求，照旧先输新值、看写入帧、确认才写）；Unit / 类型 / 单位在表头一行；底行只在有问题或有原因时出现。
76. **空面板是引导，不是示例**：居中插画 + 三步（添加组件 / 去连接 / 自动轮询，连上主站后第 2 步打勾）+ 「＋ 添加组件」；不出现任何示例数值或示例卡。
77. **编辑模式（v3）**：页头「✕ 编辑 · 面板名 ⚙ 完成」+ 一行「编辑时不会写设备」提示；卡片是安静的编辑态（surface2 底、正文色名称、⠿、右上尺寸、灰值、底行“类型 · 地址”、不打异常标签）；点卡片 = 选中（琥珀描边 + 勾），再点取消；网格最后一格是「＋ 添加组件」。面板名称 / 竖屏列数（2 / 3 / 4 分段）/ 全部面板 / 新建 / 删除面板都在 ⚙ 浮层里（页内浮层，内容可滚动）。返回键：有选中先取消选中，再按才走「放弃修改？」。
