# 注意事项（贡献与评审必读）

本文记录老板和技术总工对本项目的持续要求。**每一轮有新要求都要补进来**；不要放截图，不要放任何隐私信息。

## 一、安全与交互
1. **写入前一律确认**：任何写寄存器/线圈的入口都先弹确认层，显示“读取值 / 上次写入 → 新值”、将发送的整帧字节、超时不重试提示；**取消不发送**，点“发送”才发且只发一次。
2. **广播（Unit 0）**：确认层用红色（红色标签“广播 · 所有从站”、红色“发送广播”按钮），提示“所有从站都会执行，且不会有回应”；结果只能标“已发送”，不能写“成功”。
3. “当前”值的来源要标清：来自上次写入标「上次写入」，来自读取标「读取值」，没读过标「当前 / 未读取」；新旧值相同给一句提示（不拦截）。
4. 编辑面板（面板的编辑模式）期间**不得发送任何写入**。

## 二、视觉与布局
5. **设计稿以 v2 为准**（`docs/design/ui-v2.html` 及 `v2-b*.png`）。对不齐的必须逐项量出来对齐：间距、圆角、阴影、字号、基线、左右留白；不接受“差不多”。
6. **分段滑块同心**：选中块圆角 = 外层容器圆角 − 内边距（现为 12 − 3 = 9），四周内边距都是 3dp，左右对称；全局只有 `SegmentedControl` 一个实现，不要另写。
7. **阴影形状必须与被投影元素的圆角一致**（dock、岛、卡片）。
8. **触控区域 ≥ 48dp 优先，视觉仍用设计稿尺寸**：视觉块可以更小，但可点击的热区要补到 48dp。
9. **dock 的样式和位置是老板授意的**：底部间距贴近系统手势条上沿（约 8–12dp），内容区底部留白随之调整；**不得改回参考图的位置**。
10. 连接页：页头标题「连接」下面**不要**「主站 · 运行中」之类的副标题；卡片内标题行与内容的间距按稿面收紧，并有间距断言。
11. 连接后的「断开」条**不得遮挡**任何内容：条放在可滚动内容之外，内容区留出底部空间，滚到底最后一张卡完整可见（竖屏、横屏都要有测试）。
12. 每个视觉修复都要有断言（`getBoundsInRoot` / 像素）+ Roborazzi，含字体缩放 1.3 和窄屏；断言必须能在“去掉修复”时失败。

## 三、日志页
13. 分页（默认每页 100 帧）；工具栏有 **开始 / 暂停 / 清除 / 保存**。
14. **默认不记录，点“开始”才记录**；暂停停止记录但保留已有帧；清除清空；“暂停记录”≠“锁定滚动”，文案和图标要区分。
15. 每帧记录墙钟时间 `HH:mm:ss.SSS`，**保存的文件也带时间**（CSV 另带完整日期）。
16. 记满 20000 帧（或约 8MB）停止并提示，不静默丢旧帧。
17. 保存走系统界面（保存到文件 / 分享），**每次保存前弹隐私提示**；不申请存储权限，不上传。

## 四、面板
18. **不放空壳、不放示例卡**：没有配置点位时显示空面板和“添加组件”入口。要做就做完整功能（编辑、选类型、数值/曲线配置、系列编辑），按 `docs/panel-plan.md` 分多个 PR 逐步做，每个 PR 独立可合并。
19. 面板的实现放 app 层 `application/panel/`（纯 Kotlin、无 Android 依赖，可整体搬进 core）；序列化用 `org.json`；轮询与手动请求交错；不做后台采集；样本历史只放内存。

## 五、边界与流程
20. **协议和 `modbus-core` 不动**。依赖 core 的项目单列“暂缓清单”（`docs/deferred-core.md`），例如：会话条 TX/RX/错误计数（`SessionCounters`）、写入帧预览 `SessionManager.previewFrame()`、帧摘要 `FrameDescriber`、`TrafficEvent` 的 id/配对、`RegisterChange.source`、`ValueSimulator`。不要为了赶进度把这些做成假数据或空壳。
21. **实机截图含隐私，不进公开仓库**，也不贴进 PR 描述；PR 里只用 Roborazzi 渲染图和设计稿渲染图。
22. 本地构建用 `/opt/android/build.sh`，**一次只跑一个构建**，用完 `./gradlew --stop`。不提交录制出来的基线 PNG。
23. 不编造验证结果：没验证的写“未验证”（尤其是真机触控、字体渲染、手势条位置）。
24. 堆叠的 PR 之间用普通 `git merge` 同步，不 force push。**合并进 main 必须由老板本人在聊天里明确确认**，合并提交带 `[skip ci]`；在确认之前所有 PR 保持不合并。
25. 每个里程碑（推送 / 本地构建 / CI 结果）都记到 `board.md`。
